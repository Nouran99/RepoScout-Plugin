# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue.
Use GitHub's private vulnerability reporting for the RepoScout repository. If
that option is unavailable, contact the maintainer through the contact method
listed on the RepoScout website:

https://nouran-darwish-ai.dev/reposcout

Include the affected plugin version, reproduction steps, impact, and any
suggested mitigation. Do not include live API keys, access tokens, or personal
data in the report.

## Supported version

Security fixes are provided for the latest published plugin version.
